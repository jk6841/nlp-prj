0RESEARCH QUESTION

가격을 원화로 말하는 종목은 수익률이 낮을까?

  • 대상 · 미국 주식 종목

  • 설명 변수 · 댓글 중 가격을 달러가 아닌 원화로 표시한 비율

  • 결과 변수 · 종목의 수익률

QUESTION

미국주식 종목의 가격을 달러가 아니라 원화로 표시하는 댓글의 비율이 높은 종목의 수익률이 낮을까?

1TARGET

토스증권 커뮤니티 댓글을 모아요

  • 토스증권 앱의 종목별 커뮤니티에 달린 댓글이에요

  • 작성자는 토스증권을 쓰는 개인 투자자예요

  • 종목마다 투자자의 반응이 짧은 글로 쌓여요

WHY THIS DATA

개인 투자자가 종목을 어떻게 보는지 직접 읽을 수 있는 텍스트예요.

2METHOD

웹 화면이 쓰는 API로 댓글을 가져와요

  • 토스증권은 공식 REST API를 제공하지 않아요

  • 대신 웹 UI가 내부에서 호출하는 댓글 API를 써요

  • Cookie에 deviceId만 넣으면 값과 상관없이 요청이 성공해요

ENDPOINT wts-cert-api.tossinvest.com GET /api/v4/comments

2METHOD · RESPONSE

응답의 key로 다음 페이지를 이어 받아요

  • 댓글 본문은 message 안의 제목과 내용 두 칸에 있어요

  • key는 마지막 댓글 ID라서 다음 요청의 lastCommentId로 넘겨요

  • SOXL 한 종목에만 댓글이 1,209,515건 있어요

3PROCESSING

필요한 필드만 골라 PostgreSQL에 쌓아요

  • Airflow DAG로 수집, 정제, 적재를 한 흐름으로 묶어요

  • 응답에서 댓글 ID, 제목, 본문 같은 필드만 남겨요

  • 작성자 정보 같은 나머지 필드는 저장하지 않아요
